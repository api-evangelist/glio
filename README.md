Glio is a unified API for AI media generation that provides a single interface to 90+ models across video, image, audio, and text from providers such as Kling, ByteDance Seedance, Google Veo and Imagen, OpenAI GPT Image, Suno, ElevenLabs, Runway, and Anthropic Claude. Developers create work via an asynchronous job-based workflow (create job, poll, get result), and also call OpenAI-compatible chat-completions and embeddings endpoints synchronously. Billing is pay-per-use in GL tokens (1 GL = $0.01 USD) with no subscriptions or minimums. Surfaced as an a16z portfolio company and enriched from Glio's public developer surface at glio.io / api.glio.io.

**Areas:** Company · Artificial Intelligence · Machine Learning · Media Generation · Video Generation · Image Generation · Audio Generation · Text-to-Speech · LLM · Generative AI · API Aggregator · Developer Tools

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Glio: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
